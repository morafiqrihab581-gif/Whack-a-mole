# 🐹 Whack-a-Mole Game (JavaScript)

A simple and fun **Whack-a-Mole Game** built using **HTML, CSS, and JavaScript**.  
Click the emojis that appear randomly in the grid before time runs out! 🎯

---

## 🎮 Features

- ⏱️ 30-second countdown timer
- 🧠 Random emoji (animals) appearing in holes
- 🖱️ Click to increase score
- 🔁 Automatic game loop
- 🎯 Simple and interactive UI

---

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla JS)

## 🎯 How to Play

1. Click **Start Game** ▶️  
2. Emojis appear randomly in the holes 🐹  
3. Click them as fast as possible 🖱️  
4. Each correct click increases your score 🎯  
5. Try to get the highest score before time runs out ⏱️
